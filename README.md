# GeoRift  
Play the game here: [https://lavadev.itch.io/georift](https://lavadev.itch.io/georift)  
***Instructions for playing are in the game's menu.***  
A fast-paced 2D geometric arena shooter, where you defeat scaling waves of enemies. Features a simple, minimalistic art style with a retro feel and satisfying combat.  
Have fun!
